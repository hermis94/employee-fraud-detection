# Employee Expense Fraud Detection

**Student:** Hermis Makawa (serial no. 15, registration no. 21313351018)  
**Approach:** Unsupervised anomaly detection, as allocated in `COMPREHENSION-1.pdf`.

This project applies an Isolation Forest to employee expense claims and produces a ranked report of unusual claims for human investigation. It does not predict a verified fraud label: no ground-truth fraud outcome is available. Accordingly, the project reports the number and share of claims flagged, the model score threshold, and an anomaly-score plot, not accuracy, precision, recall, or F1.

## Data and scope

`data/employee_expense_claims.csv` is generated by `src/data.py` with a fixed seed. It contains 4,500 synthetic claims with expense category, department, vendor, payment channel, amount in MWK, receipt indicators, submission timing, recent claim volume, and employee tenure. The dataset has no fraud label. Synthetic irregularities are included to create unusual patterns for review, but their presence is not ground truth and is not used to evaluate the detector. The model excludes claim and employee identifiers. The two ZIPs in the parent directory contain SMS/token and scam-message data and do not describe employee expenses, so neither is used.

The Isolation Forest uses a 4.5% contamination setting as a review-queue capacity assumption for this demonstration. It is not a policy threshold or an estimate of the real fraud rate. A flag means “unusual relative to this dataset,” not “fraud.”

## Run

Python 3.10 or newer is recommended.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.train
```

Training regenerates the dataset and writes `artifacts/employee_expense_isolation_forest.joblib`, `artifacts/metrics.json`, `artifacts/scored_claims.csv`, `artifacts/suspicious_claim_report.csv`, and the portfolio score-distribution chart.

Score new claims using the feature columns listed in `src/data.py`:

```powershell
.\.venv\Scripts\python.exe -m src.score path\to\claims.csv --output review_queue.csv --all-scored all_scores.csv
```

## Limitations

The data and behavior are synthetic. Unsupervised anomaly scores can surface legitimate but rare activity and miss organized or common abuse. Reviewers should investigate flags using receipts, policy, and context; never automatically reject or discipline a claim based only on this score. Real evaluation needs independently adjudicated claims and monitored investigator outcomes.
